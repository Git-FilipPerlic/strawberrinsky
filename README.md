# strawberrinsky

Kamera + AI za pomoć starijima i osobama sa demencijom.

Ukućani često premeste stvari i ne sete se gde su ih ostavili. Kad uđeš u kuću,
samo izgovoriš naziv stvari koju tražiš, a strawberrinsky pronađe gde je.

## Status

Projekat je tek započet — za sada stoji samo prazan Flutter starter (Android i iOS).

## Rad na više računara

- posle rada: `git add .` → `git commit -m "..."` → `git push`
